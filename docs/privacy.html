制定日: 2026年9月25日／最終改定日: 2026年9月27日

トップ利用規約アカウント削除

SHN_apps（以下「運営者」）は、ClipMark（以下「本アプリ」）における利用者情報を、以下のとおり取り扱います。

1. 取得・保存する情報

  • Googleログインにより提供されるユーザーID、表示名、メールアドレス、プロフィール画像URL
  • 利用者が保存した動画URL、動画内の時刻、メモ、タグ、追加・更新日時
  • ClipMarkから動画を開いた回数と最終再生日時
  • YouTube Data APIから取得する動画ID、タイトル、チャンネル情報、サムネイル、動画時間、公開コメント
  • 同期状態やデータ更新時刻など、サービス提供に必要な技術情報
  • アプリインスタンスID、端末・アプリ情報、概算地域、起動や機能利用などの利用状況

公開コメントはClip候補の生成中のみ処理し、コメント全文を本アプリのデータベースへ永久保存しません。

利用状況の分析では、メモ本文、検索語、動画・配信URL、動画ID、タイトル、チャンネル名およびタグ名を送信しません。

2. 利用目的

  • ClipMarkの保存、検索、編集、再生および端末間同期
  • 動画・チャンネル情報とコメント由来のClip候補の表示
  • 障害対応、不正利用防止およびサービス改善
  • 利用状況の集計・分析および機能や操作性の改善

3. 外部サービス

本アプリは、Google Firebase（Authentication、Cloud Firestore、Google Analytics for Firebase）、Google Sign-InおよびYouTube Data API Servicesを利用します。各サービスにおける情報の取扱いには、各提供者の規約・ポリシーが適用されます。

  • Googleプライバシーポリシー
  • YouTube利用規約
  • Firebaseのプライバシーとセキュリティ

4. YouTube APIデータ

本アプリはYouTube API Servicesを使用します。動画タイトル、チャンネル名、サムネイルなどのAPIデータは、取得から30日以内に再取得または削除する方針で管理します。利用者が作成したメモやタグはYouTube APIデータではなく、アカウントを削除するまで保存されます。

5. 第三者提供

法令に基づく場合を除き、利用者情報を広告事業者等の第三者へ販売または提供しません。データはサービス提供に必要な範囲でGoogleの各サービスに送信されます。

6. 保存期間と削除

利用者がアカウントを維持している間、ClipMarkデータを保存します。アプリ内の「クラウド同期」画面からアカウントを削除すると、Firebase上のアカウントおよび関連データと端末内データが削除されます。詳しくはアカウント削除案内をご確認ください。

7. 安全管理

認証済みの利用者本人だけが自身のFirestoreデータを読み書きできるアクセス制御を行い、合理的な安全管理措置を講じます。

8. 利用者の選択

利用者はアプリ内の「プライバシーと利用規約」から利用状況データの送信を停止できます。また、Googleアカウントの設定から連携を確認・解除できます。Googleアカウントのアクセス権限

9. 改定

本ポリシーは、機能や法令・規約の変更に応じて改定することがあります。重要な変更は本ページまたはアプリ内でお知らせします。
